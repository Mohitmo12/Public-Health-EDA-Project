# Public-Health-EDA-Project
# 📊 Public Health Surveillance Analysis

## 🎯 Objective

This project analyzes a large-scale public health dataset to understand disease spread, vaccination impact, environmental influence, and severity patterns using Python.

---

## 🧰 Tools & Technologies

* Python (Pandas, NumPy)
* Data Visualization (Matplotlib, Seaborn)
* Statistical Analysis (T-test, Chi-square)
* Jupyter Notebook
  

---

## 📂 Dataset

* Public Health Surveillance Dataset
* 43,000+ records
* Includes demographic, environmental, and medical attributes

---

## 🔍 Key Analysis

### 1. Vaccination Impact

* Compared transmission rates between vaccinated and non-vaccinated groups
* Found significant reduction in transmission
* This project demonstrates real-world public health data analysis.

### 2. Environmental Factors

* AQI and humidity influence disease spread
* Higher AQI correlates with increased transmission

### 3. Age vs Disease Severity

* Older individuals show higher severity levels

### 4. Social Behavior

* High social activity increases transmission
* Compliance reduces infection risk

### 5. Time-Based Trends

* Weekly and monthly trends show outbreak patterns

---

## 📊 Statistical Tests

* **T-Test** → Vaccination effect on transmission
* **Chi-Square Test** → Gender vs Infection Risk

---

## 📈 Key Insights

* Vaccination significantly reduces disease spread
* Environmental conditions impact transmission
* Age is a major factor in severity
* Behavioral patterns influence infection risk
